# 修正履歴の次回生成への引き継ぎ監査

- 対象 #70。#55 と #64 に依存。同じ所属・本人・作業の履歴だけを読み、工程と欄ごとに最新の修正を優先して最大20件を受付時に固定する。後から追加された履歴や参考メモは受付済みジョブの入力を変えない。
- 修正前後の許可された文章を事実として、参考メモを別の欄としてモデルへ渡す。参考メモが未生成・不正・一部の修正が後続の履歴で更新済みなら、参考メモを使わず修正前後の文章を使う。履歴ID、職員名、理由、職員メモ、別本人の履歴はモデルへ渡さない。
- 所属・本人・作業の分離、最新優先、20件上限、受付後の固定、参考メモあり・なし、モデル入力をモックで確認。実Firestore・Vertexでの結合と実利用者による内容の確認は未実施。
