## アクセシビリティの記録

対象は職員の支援記録フォームの3欄と、音声入力の確認・取り消し・失敗時の表示。[REPORT](../research/REPORT.md) 第6節と第8節の「音声」、第11節の「本人・音声比較」を確認した。第6節の出典ID T0・T1・T5は読み上げの効果を本製品の作業達成へ換算できないことを示し、音声だけに依存しない方針を支える。音声入力の認識精度と訂正負担を比較した研究は今回の連鎖から確認できていない。第8節の「音声」は承認時の事前生成を対象にした判断で、職員の記録入力を音声で行うことへの直接の根拠ではない。対応する判断IDがないため、関連する節として第6節・第11節を示す。

操作結果を事実に応じて返す点は第8節A3（出典ID C0・W5・W6・W7）、通信断でも入力済みの内容を失わない点はA5（出典ID C0・N0・M1・AV0・B1）と方向が同じ。ただしA3・A5はいずれも本人画面の支援要求・承認版に関する判断で、職員の記録入力を対象にした検証ではない。本機能では「認識結果を確認してから欄へ入れる」「失敗しても入力済みの文字を残す」という形で採用した。

確認した条件は、transport・MediaRecorder・AudioContextをスタブした自動テストのみ。チーム内の操作確認（自動テスト）と、本人・現場による評価は区別する。実端末でのマイク許可拒否、騒音下の認識、キーボード操作と読み上げの順序、訂正にかかる時間は未確認。第11節の本人・音声比較は読み上げを対象にしており、職員が話した音声の認識精度は含まない。
