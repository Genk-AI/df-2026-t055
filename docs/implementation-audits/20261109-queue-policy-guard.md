# Cloud Tasksキュー設定の検査

- 対象 #47 の未検証リスク。基点は統合PR #144 の `253c973`。投入前にキューの最大並列数1、最大試行数3を取得して検査し、キュー単位のHTTPターゲット上書きも拒否する。上書きはタスク側のURLやOIDC指定より優先されるため、指定した配送先・呼出元でない可能性がある。
- 設定不一致と取得失敗ではタスクを作らず、永続化済みジョブを復旧対象として残す。機微なAPIエラーは呼出元へ出さない。初回投入と復旧の両方で検査する。
- 実キューの取得にはAPIとgeneratorに `cloudtasks.queues.get` が必要で、既存のEnqueuer権限だけでは不足する。実GCP・IAMでの結合は未検証。投入後の設定変更や、既に存在するタスクにはこの検査だけでは対応できず、変更権限の制限・監視が必要。
- 設定不一致、ターゲット・OIDC上書き、設定取得失敗時の不投入をモックでテストする。先行PRのCloud Tasks・本番環境の未検証事項は残る。
