## 撮影を始める順番

1. フェイスタオル、無地の帯紙、透明袋、テープ、撮影用端末をそろえる。手持ち品を使い、追加購入は正本の上限1,000円以内にする。紙は撮影前に裁断する。
2. [台本の完成見本案](towel-shots.md#完成見本を先に用意する) をもとに実物を1つ作り、正面・裏側を撮る。撮影担当と確認担当が、紙の向き・袋口・テープを見る。
3. 端末を固定して短く試し撮りし、両手と材料、端を押さえる動き、声が記録されているか再生して確かめる。背景の名前、名札、書類、顔を画面に入れない。
4. タオルを広げるところから仕上がり確認まで、音声付きで90〜150秒の手本を1本撮る。台本の120秒配分は目安で、早送りや声の後付けで埋めず、動作と声の対応を残す。
5. 全編を再生し、[確認票](record-template.md) に実際の時刻と結果を書く。写真が足りなければ同じ材料・配置で追加撮影し、追加分だと記録する。

録画はチームの手元と声を使います。実際の利用者の出演や個人情報を前提にしません。撮影協力者には、チーム内利用、Vertexでの解析、提出動画での公開を分けて利用範囲を確認します。

## ファイルの確認

MP4の実体、映像・音声ストリーム、秒数、サイズは、`ffprobe` を使える環境で次のように確認できます。端末内のファイルを読み、外部には送信しません。

```sh
DEMO_VIDEO="/absolute/path/towel-demo.mp4"
ffprobe -v error \
  -show_entries format=format_name,duration,size:stream=index,codec_type,codec_name,width,height \
  -of json "$DEMO_VIDEO"
```

手本の撮影条件は90〜150秒です。APIの受付上限は別に50MB・180秒と定められているので、両方を確認します。`.mp4` という拡張子だけで判定せず、利用するAPIでも形式検査を通します。`ffprobe` の音声ストリーム表示だけでは、声かけが聞き取れるとは判断できません。各動作の声を再生して確認してください。

撮影後の素材や記録は、公開リポジトリへそのまま追加せず、利用範囲を確認した保管先で管理します。実データを含む確認票はこのテンプレートから別に作り、共有前に内容を確認します。デモ素材・プロフィール・操作履歴等の11月15日の削除は、正本第3節に従って基盤担当へ引き継ぎます。
